# Project instructions

This is a hackathon project for the ACM MAJU Vibe Coding Competition.

**Always read and follow [EVALUATION.md](EVALUATION.md) before planning or changing anything.** It contains the 100-point judging rubric, the mandatory deliverables, the chosen idea's scope, and the development checklists.

On every change:
- Ask which rubric criterion it earns points on. If none, don't build it.
- Keep the primary flow complete and working before adding anything new.
- Make every new UI work at 360px wide and with a keyboard (visible focus, labeled inputs, alt text, contrast ≥ 4.5:1).
- Use only clearly labeled fictional sample data. Never use real personal or student data, and never process payments.
- When AI output is checked or corrected, add an entry to the AI Iteration Log in EVALUATION.md (section 8).
- Keep the README in sync with the template in EVALUATION.md (section 9).
