# 03 — Component catalogue

All components are in `src/components/`. They compile with `npx tsc -b`, render at 360px (checked in Chrome at 360×800, touch, reduced motion), and need **no new npm dependencies**.

**Theme tokens** (define these in `src/index.css`; every component has a fallback): `--color-primary`, `--color-on-primary`, `--color-primary-soft`, `--color-accent`, `--color-text`, `--color-muted`, `--color-surface`, `--color-surface-muted`, `--color-border`, `--color-focus`, `--color-success`, `--color-error`.

**Licences.** React Bits is MIT + Commons Clause (© David Haz). You can use it in the site, but you can't resell or redistribute the components themselves. Credit it in the README. 21st.dev SegmentedControl: MIT (@ddoemonn). `ui/*` are original.

**Lenis + GSAP (required).** SplitText, ScrollReveal and AnimatedContent use ScrollTrigger. In the Lenis setup, add `lenis.on('scroll', ScrollTrigger.update); gsap.ticker.add(t => lenis.raf(t * 1000)); gsap.ticker.lagSmoothing(0);`. Without it, scroll reveals fire late or never.

## Not used (and why)

- **21st Bottom Nav Bar (@arunachalam):** no licence listed, removes focus (`focus:outline-none focus-visible:ring-0`), hides inactive labels, and uses buttons instead of links. We wrote our own `ui/BottomNav` instead.
- **reactbits Dock:** magnification does nothing on touch, and it's a heavy file (1.2k lines).
- **reactbits MagicBento, StarBorder, BounceCards, PixelTrail:** decorative only (0 rubric points) and heavy.
- **reactbits Aurora, Grainient, Noise:** each adds a second WebGL/canvas render loop next to the R3F scene. Use a static CSS gradient or an SVG grain background instead.
- **reactbits ShinyText:** its shimmer effect lowers text contrast by design.
- **reactbits AnimatedList:** needs `@hugeicons/*`. Use `motion` AnimatePresence if it's needed.
- **reactbits ScrollFloat, FadeContent:** they duplicate ScrollReveal and AnimatedContent.
- **diceui Marquee (via 21st):** needs `@base-ui/react`. LogoLoop covers this need.
- **Other 21st.dev items (navbar, how-it-works, testimonials, footer, pricing, dialog):** the free MCP quota is 2 fetches a day and resets 2026-11-13 00:00 UTC, so they weren't fetched. Build them with the primitives above. For the inquiry form, use its own route or a native `<dialog>` (built-in focus trap and Esc).
