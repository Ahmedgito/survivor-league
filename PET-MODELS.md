## 🤖 Custom pets with AI generators
- **Meshy** (verified): the free plan gives 100 credits a month. Output is **CC-BY 4.0, you own it**, and public or commercial use is OK with the credit "Model created with Meshy – CC BY 4.0". Auto-rigging and some animation clips are available. **The best option for a one-of-a-kind hero pet**, which also helps the Originality score. Log it in the AI Iteration Log.
- **Tripo:** sources conflict on whether free outputs can be used publicly (unverified). Avoid it.
- **Hyper3D Rodin:** commercial rights seem tied to paid plans. Avoid the free tier.

## 🚫 Do not publish (local prototyping only, if at all)
| Model | Why not |
|---|---|
| Dogstudio dog (in [Abu-Fazal/first-3d-project](https://github.com/Abu-Fazal/first-3d-project)) | Owned by Dogstudio; the repo author claims no rights. **Local prototype only; swap it out before pushing.** |
| three.js `Horse` / `Flamingo` / `Parrot` / `Stork` | No license was ever recorded (three.js issue #23089, closed without one) |
| ithappy "Animals FREE" | The license forbids sharing the raw files |
| Any Fab Standard License asset | Free standalone redistribution is not allowed, which rules out a public repo |
| CGTrader "Royalty Free" free models | Raw-file redistribution risk |
| WildPoly3D Cat/Dog Animated (Sketchfab) | Personal use only |
| Sketchfab "Buy Royalty Free" cat or French bulldog | Paid store items |
| Munchkin Cat (Sketchfab) | CC BY-NC-SA (non-commercial) |
| CyberDoggo (Sketchfab) | 188k triangles, too heavy for the web |
| OpenGameArt dog, Doginx, mcsteeg PSX dog | License unverified; check before any use |
